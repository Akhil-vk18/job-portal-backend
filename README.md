# Job Listing Portal

A simple job listing portal built using **Java Servlets** and **MySQL**.  
This project allows users to view job postings with details like job title, skills required, experience, and application link.

## Features (Planned)
- Homepage with project description and latest 3 jobs
- Job listing page with filtering (Technopark/Infopark, date posted)
- Job details: Title, skills required, experience, apply link
- Backend using Java Servlets + JDBC
- Database: MySQL

## Tech Stack
- Java (Servlets, JDBC)
- MySQL
- HTML/CSS (Frontend)
- Deployed in a single repo (later may split into backend + frontend)
